# Административная панель (02_Admin_Panel)

Существующие части проекта (публичный сайт, кабинет, движок тестирования, дизайн-система) не изменяются. Админ-панель добавляется как отдельный раздел `/admin/*` поверх текущей структуры.

## Что появится

Раздел «Админ-панель» с боковой навигацией и подстраницами:

1. **Обзор** — счётчики: пользователи, активные курсы, назначения, просроченные обучения, тестирования, последние действия.
2. **Пользователи** — список с поиском и фильтрами; создание, редактирование, блокировка/восстановление, роль, подразделение, должность, профессия, история обучения.
3. **Оргструктура** — подразделения, должности, группы, руководители. Записи не удаляются физически, только деактивируются.
4. **Курсы** — создание, редактирование, архивирование, привязка к профессии, аудитория, статус; модули курса.
5. **Учебные материалы** — все типы (текст, PDF, видео, изображения, инструкции, презентации, ссылки, документы), загрузка в хранилище, статус, автор, дата публикации.
6. **Назначения обучения** — назначение сотруднику, группе, подразделению, профессии или списку пользователей; срок, обязательность, повтор, комментарий.
7. **Тесты** — банк вопросов и вариантов ответов, привязка к профессии/курсу, настройки (количество вопросов, попытки, проходной балл, случайная выборка, время), статистика.
8. **Справочники** — профессии, подразделения, должности, статусы, типы курсов, категории обучения, виды тестов.
9. **Импорт** — CSV/XLSX для пользователей, вопросов, материалов, справочников с предварительной проверкой структуры и отчётом об ошибках до записи.
10. **Экспорт** — пользователи, результаты, назначения, статистика, журнал в CSV/XLSX.
11. **Журнал действий** — входы, изменения пользователей и ролей, курсы, тесты, назначения, критические действия; только чтение.
12. **Системные настройки** — параметры платформы, уведомления, параметры тестирования по умолчанию, правила доступа, настройки хранения файлов.

## Правила доступа

- Administrator — все разделы.
- HR — пользователи, оргструктура, курсы, материалы, назначения, тесты, справочники, импорт/экспорт, журнал (чтение).
- Teacher — курсы, материалы, тесты и статистика по своим курсам.
- Manager — обзор, назначения и результаты своих подчинённых, экспорт по ним.

В текущей базе ролей нет роли Teacher — она добавляется в перечень ролей, существующие роли и данные не затрагиваются.

## Ограничения по спецификации

- Никакого физического удаления данных, влияющих на историю обучения: везде архивирование/деактивация.
- Изменение результата завершённого теста — только через отдельную форму с обязательной причиной, запись попадает в журнал.
- Выдача админ-прав — только пользователем с ролью Administrator, фиксируется в журнале.

## Техническая часть

**Миграция БД (новое, без изменения существующих таблиц):**
- `positions`, `groups`, `group_members`, `course_types`, `learning_categories`, `test_kinds` — справочники.
- `audit_log` — журнал действий (актор, действие, сущность, id, данные, время).
- `platform_settings` — системные настройки (key/value JSONB).
- `assignments` — добавление недостающих полей: группа/подразделение, обязательность, повтор, комментарий.
- Расширение enum `app_role` значением `teacher`.
- Для каждой новой таблицы: GRANT, RLS, политики (чтение — staff, запись — admin/hr), триггер `updated_at`.

**Сервер:** `src/lib/admin.functions.ts` (+ `admin.server.ts`) с `requireSupabaseAuth` — проверка роли на сервере для всех операций записи, запись в `audit_log`, валидация импорта, генерация экспорта. Клиент не пишет в служебные таблицы напрямую.

**Маршруты:** `src/routes/_authenticated/admin/route.tsx` (layout с сайдбаром и проверкой роли) + подстраницы `index`, `users`, `org`, `courses`, `materials`, `assignments`, `tests`, `dictionaries`, `import`, `export`, `audit`, `settings`. Текущий `admin.tsx` заменяется этим layout'ом.

**UI:** только существующие shadcn-компоненты и токены дизайн-системы, никакой новой стилистики. Таблицы с пагинацией, поиском и фильтрами; формы в модалках/шитах; состояния loading/empty/error через `src/components/states.tsx`.

**Данные:** `src/lib/admin-queries.ts` с `queryOptions`, инвалидация после мутаций.

## Порядок работ

1. Миграция БД (справочники, журнал, настройки, поля назначений, роль teacher).
2. Серверные функции и проверки прав + журналирование.
3. Layout админки и навигация.
4. Разделы: обзор → пользователи → оргструктура → курсы/материалы → назначения → тесты → справочники.
5. Импорт/экспорт, журнал, системные настройки.
