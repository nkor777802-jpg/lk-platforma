# Оргструктура: рабочие кнопки, фактические названия, свои иконки

## 1. Кнопки «Показать / Свернуть» не работают

Причина найдена в коде схемы: полотно с зумом при нажатии мыши сразу «захватывает» указатель для перетаскивания (`setPointerCapture` в `onPointerDown`), поэтому клик до кнопок внутри карточек не доходит — ни «Показать N», ни «Свернуть».

Что делаем:
- Перетаскивание запускается только после реального смещения указателя (порог ~4 px), захват указателя включается в этот момент, а не при первом нажатии.
- Нажатие, начатое на кнопке или ссылке, вообще не считается началом панорамирования.
- Кнопки «Развернуть всё» / «Свернуть всё» в панели инструментов остаются и работают как есть.

## 2. Фактические названия подразделений

Схема уже строится по активной штатной расстановке, но подписи в интерфейсе называют всё «департаментами», хотя в расстановке верхний уровень такой:

- АДМИНИСТРАТИВНО-УПРАВЛЕНЧЕСКИЙ ПЕРСОНАЛ — штат 9,33
- Группа планирования и автоматизации — 3,3
- Финансовая служба — 12,5
- Служба управления персоналом — 13,5
- Служба директора по информационным технологиям — 4
- Коммерческая служба — 15
- Служба маркетинга — 8,95
- Производственный департамент — 398,6

Что делаем: убираем слово «департамент» из интерфейсных подписей и используем нейтральное «подразделение» либо фактический тип единицы из расстановки (служба / группа / департамент). Затрагиваются: кнопка «Структура департамента» на карточке, подсказка внизу схемы, заголовок ветки и хлебные крошки. Названия самих единиц берутся из данных без изменений — ничего не переименовываем и не выдумываем.

## 3. Своя иконка для каждого подразделения

Для восьми верхнеуровневых единиц задаём индивидуальные смысловые иконки (по ключевым словам названия, с запасной иконкой для новых единиц):

- Административно-управленческий персонал — `Landmark`
- Группа планирования и автоматизации — `ClipboardList`
- Финансовая служба — `Wallet`
- Служба управления персоналом — `UsersRound`
- Служба директора по ИТ — `MonitorCog`
- Коммерческая служба — `Handshake`
- Служба маркетинга — `Megaphone`
- Производственный департамент — `Factory`

Иконка одинаково используется и в карточке обзора, и в заголовке ветки этого подразделения. Цветовое кодирование по брендбуку не меняется.

## Технические детали

- `src/components/org/OrgGraph.tsx` — порог перетаскивания в обработчиках указателя, отказ от захвата на кнопках, правки текстов подписей.
- `src/components/org/OrgPoster.tsx` — карта `name → icon` для верхнего уровня, использование в `IconFor`, текст кнопки перехода в ветку.
- `src/components/org/OrgBranch.tsx` — та же иконка в корне ветки.
- Данные, запросы и БД не трогаем.
