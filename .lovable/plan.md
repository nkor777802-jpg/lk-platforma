# Плавное раскрытие меню «АО «Людиновокабель»» и «Структура обучения»

## Что изменится

Выпадающие меню в верхней панели откроются мягкой анимацией вместо резкого появления:

- Плавное появление панели: лёгкий подъём снизу вверх + затухание, с небольшим масштабированием от точки клика (~180 мс на открытие, ~120 мс на закрытие).
- Пункты внутри меню появляются каскадом — один за другим с задержкой ~30 мс, что создаёт ощущение «раскрытия списка».
- Стрелка `ChevronDown` у активной вкладки плавно поворачивается на 180°.
- Наведение на пункт даёт мягкую подсветку с лёгким сдвигом вправо и оранжевым индикатором слева (фирменный акцент).
- На мобильном меню (Collapsible) — плавное раскрытие по высоте с тем же поворотом стрелки.
- Учитывается `prefers-reduced-motion`: анимации отключаются для пользователей с этой настройкой.

Цвета — только существующие семантические токены, логотип и структура пунктов не меняются.

## Технические детали

- `src/styles.css`: добавить keyframes для выпадающего меню (`dropdown-in`, `dropdown-out`) и утилиту каскадной задержки пунктов; блок `@media (prefers-reduced-motion: reduce)`.
- `src/components/public/PublicHeader.tsx`:
  - `DropdownMenuContent` — классы анимации на основе `data-[state=open]` / `data-[state=closed]` и `data-[side=*]`, `origin-top`.
  - `DropdownMenuItem` — inline `style={{ animationDelay }}` для каскада, hover-переходы.
  - Триггер — `data-[state=open]:rotate-180` на иконке, transition на цвет/фон.
  - Мобильный `CollapsibleContent` — анимации `accordion-down` / `accordion-up`, поворот стрелки через `group-data-[state=open]`.
- Правки только презентационные: маршруты, пункты и логика навигации не затрагиваются.
