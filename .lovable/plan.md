# Меню «АО «Людиновокабель»» в шапке сайта

Сейчас в верхней панели все разделы идут одним длинным рядом: Главная, О предприятии, Руководство, Обучение, Структура, Обучение по профессиям, Частые вопросы, Контакты. Ряд перегружен.

## Что меняется

1. **Новая кнопка «АО «Людиновокабель»»** в главной панели — выпадающее меню (клик/наведение) со стрелкой.
2. **Внутрь меню переносятся три раздела** (как отдельные пункты-«листы»):
   - О предприятии → `/about`
   - Структура → `/structure`
   - Руководство → `/management`
   Отдельными кнопками в верхнем ряду они больше не показываются.
3. **Остальные пункты остаются** в прежнем порядке: Главная, «АО «Людиновокабель»», Обучение, Обучение по профессиям, Частые вопросы, Контакты.
4. **Активное состояние**: если открыта любая из трёх вложенных страниц, кнопка «АО «Людиновокабель»» подсвечивается фирменным синим — как сейчас подсвечиваются активные ссылки.
5. **Мобильное меню**: тот же блок оформляется как раскрывающаяся группа с заголовком «АО «Людиновокабель»» и тремя вложенными ссылками с отступом; при переходе меню закрывается.

## Технические детали

- Правки только в `src/components/public/PublicHeader.tsx`.
- Десктоп — `DropdownMenu` из `@/components/ui/dropdown-menu`, мобайл — `Collapsible` из `@/components/ui/collapsible` (оба уже есть в проекте).
- Ссылки — `Link` из `@tanstack/react-router`, маршруты существующие, новых роутов не создаётся.
- Стили и подсветка — существующие токены (`text-secondary`, `bg-secondary/10`), новых цветов не вводится.
