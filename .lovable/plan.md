# Настройки печати: ориентация и поля A4

На странице печатной формы адаптационного плана (`/onboarding/print`) появится панель настроек, где перед печатью можно выбрать ориентацию листа и размер полей.

## Что увидит пользователь

- Блок настроек над документом (не попадает в печать):
  - **Ориентация**: Книжная (A4 portrait) / Альбомная (A4 landscape).
  - **Поля**: Узкие (8 мм) / Обычные (12 мм) / Широкие (20 мм).
  - Кнопка «Печать / PDF» рядом.
- Предпросмотр листа сразу меняет ширину (210 мм для книжной, 297 мм для альбомной) и внутренние отступы, чтобы было видно, как всё уместится.
- В альбомной ориентации таблица мероприятий получает больше места, длинные названия перестают переноситься по буквам.
- Выбор запоминается в браузере (localStorage), чтобы при следующей печати не настраивать заново.

## Технические детали

- Изменяется только `src/routes/onboarding.print.tsx`.
- Состояние `orientation` и `margin` через `useState` + сохранение в `localStorage` (чтение в `useEffect`, чтобы не ломать гидратацию).
- Правило `@page { size: A4 <orientation>; margin: <n>mm }` генерируется динамически в том же inline-`<style>`, где сейчас `PRINT_CSS`; ширина листа предпросмотра задаётся inline-стилем `maxWidth`.
- Автовызов `window.print()` при открытии сохраняется, но выполняется после применения сохранённых настроек.
- Селекты — существующие `@/components/ui/select`, отмечены классом `no-print`.
