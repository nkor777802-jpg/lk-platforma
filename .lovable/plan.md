# Кнопка «Личный кабинет» с именем сотрудника в шапке

## Что меняется
Иконка пользователя в шапке кабинета (сейчас — просто силуэт) превращается в полноценную кнопку:

- Внутри: знак логотипа компании + надпись «Личный кабинет» и имя сотрудника (только имя из ФИО)
- Обычное состояние: светлый фон, синий текст, синий знак логотипа
- При нажатии и когда открыт раздел «Профиль»: заливка корпоративным синим #112866, белый знак логотипа и белый текст
- Наведение: лёгкая синяя подложка; фокус — видимый синий контур

## Поведение
- Клик ведёт на `/profile` (как сейчас)
- Имя берётся из профиля текущего пользователя: из ФИО «Фамилия Имя Отчество» показывается только имя (вторая часть). Если ФИО из одного слова — оно; если пусто — e-mail
- Desktop (sm+): кнопка с логотипом, надписью «Личный кабинет» и именем (обрезается многоточием, чтобы шапка не ломалась)
- Мобильный: в шапке остаётся компактный вариант (знак логотипа), а пункт «Личный кабинет · Имя» добавляется в выпадающее меню

## Технические детали
- Файл: `src/components/layout/AppShell.tsx`
- Имя: `useQuery(myProfileQuery(user?.id))` из `src/lib/lms-queries.ts` (тот же запрос, что на дашборде), поле `full_name` — разбивается по пробелам, берётся вторая часть
- Логотип: `brandLogos.markBlue` в обычном состоянии, `brandLogos.markWhite` — на синей заливке; пропорции не меняются (`w-auto object-contain`)
- Цвета только через токены (`bg-secondary`, `text-secondary-foreground`), без хардкода hex
- Активное состояние — через `activeProps` у `<Link to="/profile">` плюс `active:bg-secondary`
