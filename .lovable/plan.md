# Значок уведомлений и кнопка «Админ-панель» — только для администратора и HR

## Что меняем

1. **Колокольчик уведомлений** в шапке личного кабинета показывается только пользователям с ролью «Администратор» или «HR». Преподаватели, руководители и сотрудники его не видят вовсе.
2. **Кнопка «Админ-панель»** (в шапке и в мобильном меню) показывается только администратору и HR.
3. **Преподаватели и руководители сохраняют доступ к панели** по прямой ссылке `/admin` с прежним паролем; внутри они видят только свой ограниченный набор разделов (как сейчас настроено по ролям). Ничего не урезаем и не расширяем.

## Технически

- `src/components/layout/AppShell.tsx`: `canAccessAdmin` для отображения кнопки заменяется на проверку `isStaff` (admin | hr); `<NotificationBell />` рендерится под тем же условием. Проверка ролей берётся из `useAuth`.
- Ролевая матрица разделов в `src/routes/_authenticated/admin/route.tsx` и серверные проверки не меняются — доступ преподавателя/руководителя по прямой ссылке остаётся рабочим.
- Изменения только в отображении (frontend), логика уведомлений и пароля не затрагивается.
