# КабельТрис на мобильном: экран, касания, ресурсы

## 1. Игровое поле по ширине экрана

Сейчас поле ограничено `max-w-[min(100%,28rem)]` и пропорцией 6×10. На телефоне
поле занимает всю ширину, но по высоте вылезает за экран вместе с шапкой кабинета,
HUD и подсказками — приходится скроллить во время игры.

Что сделаем:
- Поле вписывается в доступную высоту: ограничение по `min(100%, calc((100dvh - запас) * 6/10))`,
  чтобы вся сетка была видна без прокрутки.
- Страница игры на мобильном получает компактный режим: заголовок и хлебные крошки
  в одну строку, карточка «Следующая» — мельче и рядом с HUD.
- HUD на узком экране: «Счёт», «Комбо» и прогресс заказа в компактной сетке,
  кнопки «Пауза»/звук — иконками.
- Отключаем скролл-«резинку» страницы во время игры (уже есть `touch-none` на поле,
  добавим `overscroll-contain` на контейнер страницы).

## 2. Управление касанием

Сейчас работают только свайпы (влево, вправо, вниз), минимальная дистанция 28px —
на маленьком экране это неудобно и неочевидно.

Что добавим (свайпы сохраняем):
- Тап по колонке поля — падающая карточка перемещается в эту колонку.
- Двойной тап / тап по нижней зоне — быстрый сброс вниз.
- Экранные кнопки под полем: «влево», «вниз», «вправо» — крупные, с областью нажатия
  не меньше 44px, показываются только на сенсорных/узких экранах.
- Обновляем текст подсказки внизу под фактические жесты.

Логику движка (`useCabletris`, `engine.ts`) не меняем — только новые вызовы `move`/`drop`.

## 3. Ресурсы и кэш в кабинете

Фото продукции: 3 PNG общим весом 1.1 МБ (`public/cabletris/products`), каждый
рисуется в клетке ~50px, но грузится в полном разрешении и повторяется в каждой ячейке.

Что сделаем:
- Готовим лёгкие версии изображений (сжатие + размер под клетку), исходные файлы
  оставляем для крупных карточек.
- Предзагрузка картинок при старте игры, чтобы плитки не «мигали» пустотой.
- Явные `width`/`height`, `decoding="async"`, `loading="eager"` для игровых плиток и
  `loading="lazy"` для превью в каталоге игр.
- Долгоживущий кэш статики игры (иммутабельные имена файлов), чтобы при повторных
  заходах в кабинет ресурсы не скачивались заново.

## Технические детали

- Затрагиваются: `CabletrisBoard.tsx`, `CabletrisHud.tsx`, `CabletrisGame.tsx`,
  `ProductCard.tsx`, `public/cabletris/products/*`, при необходимости `adapter.ts`
  (пути к облегчённым изображениям).
- Только фронтенд и статика: правил игры, подсчёта очков, серверных функций и
  базы данных не касаемся.
- Цвета — только через существующие токены бренда, без хардкода.

## Проверка

Прогон `/gamification/cabletris` в headless-браузере на ширине 390px и 768px:
поле помещается целиком, тап и свайп двигают карточку, консоль чистая; замер веса
загруженных изображений до и после.
