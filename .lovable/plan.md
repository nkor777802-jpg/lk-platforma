# ФИО руководителей: публично только топ-уровень

Сейчас страница `/structure` доступна без входа и отдаёт ФИО руководителей **всех**
подразделений (в `getPublicOrgStructure` поле `managerName` возвращается без проверки
авторизации). ФИО рядовых работников уже скрыты. Нужно оставить публично только
топ-руководство.

## Что изменится

- **Без входа** на публичной схеме ФИО показываются только для:
  - АО «Людиновокабель» / генерального директора (уровень 0);
  - подразделений верхнего уровня — служб и департаментов (уровень 1).
  Для всех остальных подразделений остаётся только должность руководителя.
- **После входа в систему** (внутренняя страница оргструктуры) ФИО видны как сейчас —
  для всех подразделений.
- Подпись под публичной схемой уточняется: сейчас там «Персональные данные работников
  на публичной схеме не отображаются», станет — что публично показывается только
  руководство верхнего уровня.

## Технические детали

- `src/lib/public.functions.ts` → `getPublicOrgStructure`: отдавать
  `managerName: u.level <= 1 ? u.managerName : null`. Логика фильтрации на сервере,
  чтобы скрытые ФИО не попадали в ответ вообще.
- `src/lib/org-versions.server.ts`: оставить `managerName: u.manager_name` без изменений —
  фильтрация делается на уровне публичной функции, внутренние экраны и экспорт
  продолжают получать полные данные.
- `src/routes/_public/structure.tsx`: обновить текст примечания под схемой.
- Компоненты (`OrgPoster`, `OrgBranch`, `OrgGraph`, `OrgChart`) не меняются — они уже
  корректно скрывают строку, когда `managerName` пустой.
