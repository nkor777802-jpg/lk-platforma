# Анимация «Этапы обучения» на странице /training

## Что меняем

На странице `/training` в секции «Этапы обучения» карточки сейчас появляются одновременно, а заголовок и описание видны сразу. Нужно:

- Карточки этапов открываются последовательно от 1 к 5 с задержкой между ними.
- В каждой карточке заголовок и описание появляются «набором» (typewriter), а не сразу целиком.

## Как будет

- Создаём локальный компонент `AnimatedStageList` прямо в `src/routes/_public/training.index.tsx`, чтобы анимация работала только на этой странице.
- Каждая карточка запускает CSS-анимацию `fade-in` с задержкой `index * 300 ms`.
- После появления карточки последовательно набираются: сначала заголовок, затем описание. Интервал между символами — около 25–40 мс.
- Номер в круге остаётся видимым сразу.
- Учитываем `prefers-reduced-motion`: при отключённых анимациях текст показывается полностью без задержек.

## Файлы

- `src/routes/_public/training.index.tsx` — добавить локальный компонент `AnimatedStageList` и заменить им `<StageList items={stages} />`.
- `src/styles.css` — при необходимости добавить keyframes для курсора typewriter (мигание). Использовать только существующие фирменные токены.

## Проверка

- Открыть `/training`, прокрутить до секции «Этапы обучения».
- Убедиться, что карточки появляются одна за другой.
- Убедиться, что в каждой карточке сначала набирается заголовок, затем описание.
- Проверить, что при `prefers-reduced-motion: reduce` текст виден полностью сразу.
