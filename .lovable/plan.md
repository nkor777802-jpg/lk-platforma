# Корпоративный сайт «Людиновокабель» — публичная часть платформы

Публичный сайт информирует о предприятии и обучении и ведёт пользователя ко входу в личный кабинет. Функции ЛК не дублируются.

## Структура страниц

- `/` — главная: главный экран, о предприятии, о платформе обучения, профессии, преимущества, этапы обучения, FAQ, контакты
- `/about` — о предприятии подробнее
- `/training` — как устроено обучение (доступ, формат, фиксация результатов)
- `/professions` — публичный каталог профессий (карточка: название, краткое описание, направление производства, программы; прохождение — только после входа)
- `/faq` — частые вопросы
- `/contacts` — адрес, телефон, email, ответственное подразделение, форма обращения
- `/privacy` — политика конфиденциальности
- `/consent` — согласие на обработку персональных данных

Существующий `/` (текущий лендинг) будет переработан. Приватные маршруты не затрагиваются.

## Шапка и подвал

- Общий публичный layout: логотип (по правилам брендбука), короткая навигация, кнопка «Войти», мобильное меню (Sheet).
- Подвал: полное наименование, адрес, контакты, ссылки на политику и согласие, ссылка на вход.

## Профессии на публичной части

Каталог читается из таблицы профессий через серверную функцию с публичным клиентом (только опубликованные, поля без чувствительных данных) — без обращения к защищённым функциям, чтобы страница работала при SSR/пререндере. Если политики чтения для анонимного доступа нет, добавляется узкая политика `TO anon SELECT` + GRANT только на публичные поля профессий.

## Форма обратной связи (Контакты)

- Поля: ФИО, подразделение/должность, email или телефон, сообщение; обязательные помечены.
- Валидация через zod + react-hook-form, обязательный чекбокс согласия на обработку ПДн — без него отправка заблокирована.
- Отправка через серверную функцию, запись в новую таблицу обращений (RLS: insert разрешён всем, чтение — только HR/админ; GRANT для anon/authenticated на insert).

## Оформление

Только существующие design tokens (`src/styles.css`), шрифт Golos Text, логотипы из `src/assets`. Деловой промышленный стиль по брендбуку, без новой стилистики. Адаптив, доступность (контраст, фокус, подписи полей, смысл не только через цвет).

## SEO и производительность

- Уникальные `head()` на каждом маршруте: title, description, og:title/og:description, og:type, twitter:card, canonical на листовых маршрутах.
- JSON-LD: Organization на корне, FAQPage на `/faq`, BreadcrumbList на вложенных.
- `public/robots.txt` (приватные маршруты закрыты), `public/sitemap.xml` с публичными URL, favicon.
- Изображения с alt, `loading="lazy"`, без тяжёлого видео.

## Технические детали

- TanStack Router: `src/routes/_public/route.tsx` (layout с шапкой/подвалом) и листовые маршруты под ним; компоненты секций в `src/components/public/`.
- Данные — TanStack Query + `queryOptions`, загрузка в loader через `ensureQueryData` там, где данные публичные.
- Контент (тексты о предприятии, преимущества, этапы, FAQ, контакты) выносится в `src/content/site.ts` для правки в одном месте; заведомо непроверяемые факты (точные телефоны, адрес) заполняются плейсхолдерами, которые вы затем подтвердите.
