# Личный кабинет сотрудника (04_Personal_Account)

Существующие части (публичный сайт, админ-панель, движок тестирования, дизайн-система) не меняются. Кабинет достраивается поверх текущей архитектуры `_authenticated`.

## Что уже есть
- `/dashboard` — сводка (прогресс, попытки, достижения), `/profile` — данные сотрудника и достижения.
- Таблицы `assignments`, `courses`, `course_modules`, `materials`, `learning_progress`, `test_attempts`, `employee_achievements`.

## Чего не хватает (проверено по схеме БД)
- Нет таблиц уведомлений и сертификатов.
- Нет страниц «Мое обучение», «Страница курса», «Тесты», «Результаты», «Развитие», «Сертификаты».
- В навигации кабинета нет соответствующих пунктов.

## Что появится

1. **Главная (`/dashboard`, доработка)** — приветствие, текущие назначения, прогресс, ближайшие сроки, последние результаты, уведомления, быстрые действия.
2. **Мое обучение (`/learning`)** — вкладки: назначенные, в процессе, завершенные, просроченные. Карточка: название, статус, срок, прогресс, кнопка «Продолжить».
3. **Страница курса (`/learning/$courseId`)** — описание, содержание, уроки/модули, материалы, прогресс, условия завершения, переход к тесту. Отметка прохождения урока пишется в `learning_progress`.
4. **Тесты (`/tests`)** — доступные тесты по профессии и назначениям, число попыток, интервалы, статус доступности.
5. **Результаты (`/results`)** — список попыток: тест, дата, номер попытки, процент, статус, итог; детализация по настройкам теста; ссылка на существующую `/results/$attemptId`.
6. **Развитие (`/development`)** — история обучения (программы, даты, результаты, квалификационные этапы) и достижения. История не удаляется при смене должности.
7. **Сертификаты (`/certificates`)** — открыть, скачать, дата выдачи, срок действия.
8. **Профиль (`/profile`, доработка)** — контактные данные, статус, история обучения; редактирование сотрудником только разрешенных полей (телефон, аватар, контактный e-mail); кадровые поля только для чтения.
9. **Уведомления** — колокольчик в шапке и список: новое назначение, приближается срок, просрочено, доступен тест, результат теста, сообщение преподавателя, обновление программы.

## Ограничения
Сотрудник не может менять свои результаты, назначать обучение, редактировать курсы и видеть данные других сотрудников — это обеспечивается политиками доступа (только свои записи) и серверной проверкой при записи.

## Техническая часть

**Миграция БД:**
- `notifications` (user_id, type, title, body, link, is_read) — чтение и отметка прочтения только своих записей.
- `certificates` (user_id, course_id/profession_id, title, number, issued_at, expires_at, file_url, attempt_id) — сотрудник видит только свои; выдача только сервером.
- В `profiles` добавить `phone` и `status` для контактных данных и статуса.
- Для каждой новой таблицы: GRANT, RLS, политики, триггер `updated_at`.

**Сервер:** `src/lib/account.functions.ts` (+ `account.server.ts`) с `requireSupabaseAuth`: `updateMyProfile` (белый список полей), `markNotificationRead`, `completeModule`, `issueCertificate` (по завершённой аттестации), `getCertificateHtml`. Клиент не пишет в результаты и назначения.

**Данные:** `src/lib/account-queries.ts` с `queryOptions` (назначения с курсами, курс с модулями и материалами, уведомления, сертификаты, история) и инвалидация после мутаций.

**Маршруты:** `src/routes/_authenticated/learning.index.tsx`, `learning.$courseId.tsx`, `tests.tsx`, `results.index.tsx`, `development.tsx`, `certificates.tsx`; доработка `dashboard.tsx` и `profile.tsx`. Существующая `results.$attemptId.tsx` сохраняется.

**UI:** только существующие shadcn-компоненты и токены дизайн-системы. Навигация `AppShell` перестраивается под пункты спецификации (Главная, Мое обучение, Тесты, Результаты, Развитие, Сертификаты, Профиль); справочные разделы (О компании, Продукция, Библиотека, Видео) уходят во вторичное меню. Мобильная версия: карточные списки, крупные кнопки, доступ к курсу, материалу, тесту, результату и уведомлению.

## Порядок работ
1. Миграция (уведомления, сертификаты, поля профиля).
2. Серверные функции и запросы.
3. Навигация и главная страница.
4. Мое обучение → страница курса → тесты → результаты.
5. Развитие, сертификаты, профиль, уведомления.
