# Актуализация README.md и AGENTS.md

Документация отстала от последних изменений: в ней нет модуля документов по
персональным данным, экрана обязательного согласия и обновлённой шапки сайта.

## README.md

- **Публичный сайт**: кнопка «Моё обучение» в шапке (ведёт в личный кабинет
  для авторизованных, на вход — для гостей), кнопка выхода; главная страница —
  только hero-блок, остальные разделы через меню.
- **Новый раздел «Документы по персональным данным»**:
  - три документа для сайта и три бланка для подписи хранятся в приватном
    хранилище, версии сохраняются в истории;
  - публично и в личном кабинете документ можно только открыть для просмотра;
  - скачивание и загрузка новых версий — только `admin` и `hr` в админ-панели
    (Настройки → «Документы по ПД»); загруженный файл автоматически становится
    актуальным;
  - при первом входе работник обязан подтвердить согласие галочкой, без этого
    доступ в личный кабинет заблокирован экраном согласия.
- **Админ-панель**: добавить вкладку документов по ПД в перечень разделов.
- **Структура проекта**: упомянуть `src/components/admin/LegalDocsManager.tsx`,
  `src/components/public/LegalDocsDownload.tsx`, `src/lib/legal.functions.ts`,
  `src/lib/legal-queries.ts`, роут `/legal-consent`.

## AGENTS.md

- Раздел «Документы по ПД и согласия»: публичные документы отдаются через
  `listPublicLegalDocuments` (`src/lib/public.functions.ts`) подписанными
  ссылками только на просмотр; скачивание не выносить в публичную часть.
- Согласия фиксируются в таблице `legal_consents`; проверка выполняется в
  `beforeLoad` роута `src/routes/_authenticated/route.tsx` — не обходить её и
  не создавать циклов редиректа со страницей `/legal-consent`.
- Файлы юрдокументов лежат в приватном бакете; доступ только через серверные
  функции с проверкой ролей.

Правки только в документации, код не затрагивается.
