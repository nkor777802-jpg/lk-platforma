# Пересборка админ-панели под 02_Admin_Panel_FINAL_v2

Существующие модули (публичный сайт, кабинет, тестирование, развитие, геймификация, аналитика) не перепроектируются. Админ-панель приводится к спецификации: центр импорта на официальных Excel-шаблонах, история импорта, совместимый Excel-экспорт, производственные данные, обновлённый обзор.

## Что не совпадает сегодня

- Импорт — один общий CSV-экран на 5 типов: без шаблонов, без протокола предварительной проверки, без режима «создать и обновить», без истории. Нужно 10 отдельных типов с фиксированными шаблонами XLSX.
- Экспорт — только CSV, колонки не совпадают со структурой шаблонов импорта. Нужен XLSX с теми же колонками (цикл выгрузить → отредактировать → загрузить).
- Нет уникальных кодов (`EMP001`, `COURSE001`, `Q001`…) у сотрудников, курсов, разделов, уроков, материалов, вопросов, тестов — связывание файлов по кодам сейчас невозможно.
- Производственных данных нет вообще: рабочие центры, маршруты, конструкция 3D, материалы, дефекты, 3D-ресурсы, коды и категории продукции. Есть только витринная таблица продукции для сайта.
- Нет истории импортов и протоколов.
- Обзор админки не показывает производственные счётчики, последние импорты и ошибки импорта.

## Что будет сделано

### 1. База данных (только добавление)

- Уникальные колонки `code` для сотрудников, курсов, разделов курса, материалов, вопросов, тестов (и там, где ещё нет — для подразделений, должностей, профессий).
- Новая таблица уроков курса (раздел → урок, порядок, тип материала, файл/URL, текст, продолжительность, обязательность).
- Производственный паспорт: категории продукции, продукция, рабочие центры, маршруты, конструкция 3D, материалы, дефекты, 3D-ресурсы. У всех — коды, признак активности, GRANT, RLS (чтение — авторизованные, запись — admin/hr/teacher), триггер обновления.
- Таблица истории импортов: дата, пользователь, тип, имя файла, строк, создано, обновлено, пропущено, ошибок, статус, JSON-протокол.
- Никаких удалений и изменений существующих колонок.

### 2. Серверный слой

- `src/lib/import-schemas.ts` — по одной схеме на тип данных: имя листа, обязательные и необязательные колонки, типы значений, связи по кодам. 10 типов: Сотрудники, Подразделения, Профессии, Курсы, Структура курса (2 листа), Учебные материалы, Банк вопросов, Тесты, Назначения, Производственный паспорт (8 листов).
- `src/lib/import.server.ts` — разбор XLSX/CSV, нормализация заголовков (обрезка пробелов, порядок не важен), предварительная проверка с ошибками вида «лист / строка / колонка / значение / причина / рекомендация», сопоставление кодов со справочниками, сводка «новые / будут обновлены / без изменений / ошибки», коммит в режиме «создать новые и обновить существующие», запись в журнал действий и историю импортов.
- `src/lib/export.server.ts` — генерация XLSX с колонками ровно из шаблонов импорта плюс отчёты: результаты тестирования, обучение, банк вопросов с фильтрами (профессия, курс, тема, активные/архивные), производственный паспорт целиком.
- Генерация пустых шаблонов XLSX прямо из схем — кнопка «Скачать шаблон Excel».
- Библиотека: `xlsx` (SheetJS) — чистый JS, совместим с серверным рантаймом.

### 3. Интерфейс админки

- `/admin/import` — переработан: карточки по типам данных (название, описание, обязательные и необязательные колонки, пример, дата и автор последнего импорта, шаблон, загрузка файла). Экран проверки: сводка, таблица ошибок, подтверждение, протокол результата.
- `/admin/import-history` — история импортов с открытием протокола.
- `/admin/export` — карточки экспорта в XLSX, совместимые со шаблонами, плюс отчёты; CSV остаётся дополнительной опцией.
- `/admin/production` — новый раздел с вкладками: Продукция, Рабочие центры, Маршруты, Конструкция 3D, Материалы, Дефекты, 3D-ресурсы. Редактирование через существующий `EntityManager`.
- Обзор `/admin` — добавляются счётчики: профессии, тренажёры, рабочие центры, категории продукции, последние импорты, ошибки импорта.
- Пункты «Производственные данные» и «История импорта» в существующее меню админки.
- Права по ролям как в спецификации: Administrator — всё; HR — сотрудники, оргструктура, профессии, группы, назначения, результаты, отчёты, развитие; Teacher — курсы, уроки, материалы, вопросы, тесты; Manager — своё подразделение, назначения, результаты, аналитика. Проверка ролей на сервере в каждой операции записи.

### 4. Правила данных

- Импорт никогда не удаляет записи — только создаёт и обновляет; вывод из работы через статус «Неактивна».
- Результаты тестов, завершённые обучения, история развития и протоколы не удаляются.
- Импорт, экспорт, изменение ролей и производственных данных фиксируются в журнале действий.

## Порядок работ

1. Миграция БД (коды, уроки, производственные таблицы, история импортов).
2. Схемы шаблонов и генерация XLSX-шаблонов.
3. Движок импорта: предварительная проверка → ошибки → подтверждение → протокол.
4. Экспорт XLSX по тем же колонкам и отчёты.
5. Разделы интерфейса: импорт, история, экспорт, производственные данные, обновлённый обзор.
6. Проверка сквозного цикла «шаблон → заполнение → импорт → отображение в модуле → экспорт».
