# Оргструктура на публичной части сайта

Сейчас структура доступна только авторизованным пользователям (`/structure` и админка), а в базе ещё нет ни одной опубликованной версии. Чтобы схема появилась на сайте предприятия, нужно загрузить данные из файла штатной расстановки и открыть их для гостей.

## Что будет сделано

1. **Данные.** Импорт файла «ШР_ЛК_ДЛЯ_Структуры.xlsx» через существующий мастер и публикация версии как действующей — после этого схема наполнится реальными подразделениями и должностями.
2. **Публичный доступ.** Разрешить гостям чтение только опубликованной (действующей) версии структуры. Черновики и архивные версии остаются доступны только сотрудникам.
3. **Конфиденциальность.** На публичной части показываем подразделения, руководителей подразделений, названия должностей и численность. ФИО рядовых сотрудников и вакансии наружу не выводим.
4. **Блок на главной странице.** В публичной главной появится секция «Структура предприятия»: краткие цифры (подразделений, должностей, численность), верхний уровень структуры карточками и кнопка «Смотреть полную схему».
5. **Отдельная публичная страница `/structure`** с красивой интерактивной схемой: раскрытие/сворачивание веток, поиск по подразделениям и должностям, зум и перетаскивание на десктопе, пошаговый drill-down на телефоне, дыхание фирменных цветов (оранжевый — верхний уровень, синий — подразделения, бирюзовый — производственные участки). Экспорт в Excel/PNG/PDF остаётся только для сотрудников.
6. **Навигация.** Пункт «Структура» добавляется в меню публичного сайта; раздел для сотрудников продолжает работать как сейчас.

## Технические детали

- Миграция: `GRANT SELECT` и политики `TO anon` на `org_versions`, `org_snapshot_units`, `org_snapshot_positions` — с условием, что версия имеет статус `active`. Таблица `org_snapshot_assignments` (персональные назначения) наружу не открывается.
- Новая серверная функция `getPublicOrgStructure` в `src/lib/public.functions.ts` без `requireSupabaseAuth`, читает через publishable-клиент (`src/lib/public-supabase.server.ts`) только активную версию и возвращает агрегаты без персональных данных.
- Публичная страница: `src/routes/_public/structure.tsx` с собственным `head()` (title, description, og-теги).
- Компоненты: переиспользуем `src/components/org/OrgChart.tsx`, добавляя режим `variant="public"` (без ФИО и без панели экспорта); новый лёгкий блок `src/components/public/OrgStructurePreview.tsx` для главной.
- Ссылка добавляется в `src/components/public/PublicHeader.tsx` и `PublicFooter.tsx`, секция — в `src/routes/_public/index.tsx`.
- Импорт данных выполняется через уже готовый мастер `/admin/org` → «Импорт ШР» → «Версии» (публикация); при необходимости прогон и проверку сделаю сам.
