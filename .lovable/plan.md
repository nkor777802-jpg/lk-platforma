## README.md — переписать полностью

Разделы:
- **О проекте** — корпоративная платформа обучения, аттестации и оргструктуры АО «Людиновокабель».
- **Возможности** — публичный сайт (о предприятии, руководство, оргструктура, профессии, FAQ, контакты), личный кабинет (курсы, тесты, результаты, сертификаты, онбординг, развитие, геймификация, библиотека, 3D-тренажёр), админ-панель (пользователи, назначения, тесты, курсы, материалы, справочники, импорт штатной расстановки, аналитика, аудит, экспорт, настройки).

- **Стек** — TanStack Start, React 19, TypeScript, Vite, Tailwind v4, shadcn/ui, TanStack Query, Lovable Cloud (БД, авторизация, storage), серверные функции.
- **Структура проекта** — таблица: `src/routes/_public`, `src/routes/_authenticated`, `src/routes/_authenticated/admin`, `src/components/org`, `src/lib/*.functions.ts` / `*.server.ts` / `*-queries.ts`.

- **Локальный запуск** — сохранить блок с `npm i` / `npm run dev`, добавить упоминание переменных окружения Lovable Cloud.
- **Дизайн-система** — фирменные цвета через токены в `src/styles.css`, шрифт Golos Text, справочник `src/lib/brand.ts`; хардкод цветов запрещён.
