# Оргструктура: читаемый обзор на одном листе

Сейчас схема перегружена: сотни узлов, мелкий текст, раскрывающиеся панели уезжают вниз. Меняем логику на два уровня просмотра.

## 1. Обзорная схема (на одном листе)

Публичная `/structure` и внутренняя `/org-structure` показывают только верхний уровень, без вложенных панелей:

```text
                 ГЕНЕРАЛЬНЫЙ ДИРЕКТОР
                  ФИО · штат 465
   ┌────────┬────────┬────────┬────────┬────────┐
  [Депт]  [Депт]  [Депт]  [Депт]  [Депт]  [Депт]
```

- Во главе — карточка генерального директора (ФИО из штатной расстановки, должность, общая численность). Название предприятия — подписью над ней.
- Ниже — сетка карточек департаментов/служб (адаптивно 3-4-5 в ряд, перенос на строки, а не одна длинная линия). Карточка: иконка, название, руководитель, число отделов, штат. Никаких мелких списков отделов внутри — только счётчик «12 отделов».
- Схема помещается в экран без зума и горизонтальной прокрутки; кнопки зума/панорамы на обзоре не нужны.
- Цветовое кодирование по брендбуку сохраняем (оранжевый — руководство, синий — службы, бирюзовый — участки).

## 2. Структура департамента (по запросу)

Клик по карточке департамента открывает его схему отдельно:

- Заголовок с хлебными крошками «Генеральный директор → Департамент» и кнопкой «Назад к общей структуре».
- Внутри — вертикальное дерево департамента (отделы → участки → смены), с зумом/панорамой и поиском, как сейчас, но только по этой ветке. Крупный шрифт, компактные карточки.
- Глубокие узлы раскрываются кликом (свёрнуто по умолчанию), карточка узла открывает боковую панель с должностями, сотрудниками и рабочими центрами — как сейчас.
- Ветка отражается в URL (`?dept=<ключ>`), чтобы ссылку можно было отправить, а печать/экспорт работали для выбранной ветки (уже поддерживается `focus` в `org.print.tsx`).

## 3. Мобильный вид

Тот же принцип: список карточек департаментов → тап → структура департамента с пошаговым drill-down. Поиск ищет по всей структуре и переводит сразу в нужный департамент.

## Данные

Источник не меняем — только активная версия штатной расстановки. Ничего не выдумываем: если у корня нет ФИО генерального директора, показываем «Генеральный директор» без имени.

- Новый `src/components/org/OrgBranch.tsx` — дерево одной ветки (вынести `BranchNode`, добавить свёртку узлов).
- `src/components/org/OrgGraph.tsx` — управляет режимом: `overview` без зума, `branch` с зумом/панорамой/поиском; синхронизация выбранной ветки с URL-параметром.
- Страницы `_public/structure.tsx`, `_authenticated/org-structure.tsx`, админ-просмотр — без изменений API, только прокидывание параметра ветки.
- Мобильная ветка `OrgGraph` переиспользует ту же навигацию.
