# Группировка пунктов главной панели

Сейчас в верхней панели все разделы идут одним длинным рядом: Главная, О предприятии, Руководство, Обучение, Структура, Обучение по профессиям, Частые вопросы, Контакты. Ряд перегружен.

## Что меняется

1. **Кнопка «АО «Людиновокабель»»** — выпадающее меню со стрелкой, внутри «листы»:
   - О предприятии → `/about`
   - Структура → `/structure`
   - Руководство → `/management`

2. **Кнопка «Структура обучения»** — второе выпадающее меню, внутри:
   - Структура обучения → `/training` (пункт «Обучение» переименовывается)
   - Возможные профессии для обучения → `/training/professions` (пункт «Обучение по профессиям» переименовывается)

3. **Итоговый верхний ряд**: Главная · АО «Людиновокабель» · Структура обучения · Частые вопросы · Контакты. Перенесённые пункты отдельными кнопками больше не показываются.

4. **Активное состояние**: если открыта любая вложенная страница, соответствующая кнопка-меню подсвечивается фирменным синим — как сейчас подсвечиваются активные ссылки.

5. **Мобильное меню**: обе группы оформляются как раскрывающиеся блоки с заголовком и вложенными ссылками с отступом; при переходе меню закрывается.

## Технические детали

- Правки только в `src/components/public/PublicHeader.tsx`.
- Десктоп — `DropdownMenu` из `@/components/ui/dropdown-menu`, мобайл — `Collapsible` из `@/components/ui/collapsible` (оба уже есть в проекте).
- Ссылки — `Link` из `@tanstack/react-router`; маршруты существующие, новых роутов не создаётся.
- Заголовки самих страниц `/training` и `/training/professions` не трогаем — меняются только подписи в меню.
- Стили и подсветка — существующие токены (`text-secondary`, `bg-secondary/10`), новых цветов не вводится.
