# Позиция «Службы безопасности» в оргдиаграмме

## Что сделать
Переместить карточку «Служба безопасности» на второе место в ряду верхних подразделений — сразу после «Административно-управленческого персонала».

Итоговый порядок верхнего уровня:
```text
1. Административно-управленческий персонал
2. Служба безопасности
3. Группа планирования и автоматизации
4. Финансовая служба
5. Служба управления персоналом
6. Служба директора по информационным технологиям
7. Коммерческая служба
8. Служба маркетинга
9. Производственный департамент
```

## Технические детали
- В `org_snapshot_units` активной версии выставить `sort_order = 2` для `root/служба безопасности` (АУП = 1, следующий узел = 19, конфликтов нет).
- Дочерний «Отдел безопасности» получает соответствующий порядок внутри своей службы.
- Численность и связи уже пересчитаны ранее: служба безопасности — штат 2, служба управления персоналом — 11,5, отдел персонала — 10. Дополнительных изменений в коде схемы не требуется, она строится из данных.
