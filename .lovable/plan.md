# Пересборка геймификации: производственный 3D-тренажёр

Модуль «Развитие навыков» перестраивается вокруг производственного паспорта. Единственный источник данных — таблицы паспорта (продукция, рабочие центры, маршруты, конструкция, материалы, дефекты, 3D-ресурсы), загружаемые через центр импорта. Новая продукция начинает работать без изменений кода.

## Что меняется

### 1. Производственный тренажёр (основной сценарий)
Пошаговый путь: категория продукции → марка → автоматически построенный маршрут → на каждом шаге выбор рабочего центра → подтверждение операции → на 3D-модели появляется новый конструктивный слой → следующая операция → полностью собранный кабель.

- Маршрут строится из таблицы маршрутов по коду марки; жёстко зашитых маршрутов нет.
- Для одной операции допускается несколько рабочих центров — любой разрешённый считается верным.
- Проверка выбора выполняется только на сервере; клиент не получает признак правильности заранее.
- Фиксируются ошибки, неверные рабочие центры, время шага и число попыток.

### 2. Интерактивная 3D-модель
Процедурная генерация на three.js по данным листа «Конструкция_3D»: жила, скрученные жилы, изоляция, экран, броня, оболочка. Статичных картинок нет.

Управление: вращение, масштабирование, свободная камера, скрытие слоёв, прозрачность, exploded view, поперечное сечение, подписи элементов, режим «Разобрать кабель». Модель грузится только в браузере (без SSR).

### 3. Контроль качества «Найди дефект»
Дефекты берутся из справочника дефектов по процессу и категории продукции. После нахождения показываются причина, последствия и корректирующие действия.

### 4. Виртуальный завод
Участки приводятся к реальным процессам: волочение, скрутка, изолирование, бронирование, экструзия, испытания, упаковка. Участок открывается по факту успешного выполнения операций соответствующего процесса на реальных рабочих центрах.

### 5. Достижения и рейтинги
Добавляются уровни и опыт (XP) сотрудника, производственные значки. Рейтинги: сотрудники, подразделения, профессии.

### 6. Аналитика и интеграция
Прохождения передаются в личный кабинет, профессиональное развитие, историю результатов и аналитику: ошибки, неверные рабочие центры, длительность, попытки, самые сложные операции и конструкции.

### 7. Старые тренажёры
Задания старых типов (сборка/маршрут/сопоставление на practical_tasks) убираются из интерфейса сотрудника и из админ-вкладок; их место занимают паспортные сценарии. История результатов сохраняется.

### 8. Демо-данные
В миграции добавляются 2–3 марки кабеля с рабочими центрами, маршрутами, слоями конструкции, материалами и дефектами, чтобы тренажёр работал сразу. Реальный паспорт импортируется поверх через админ-панель.

## Технические детали
- Новые таблицы: `simulator_runs` (запуск: пользователь, марка, статус, время, счёт) и `simulator_steps` (шаг маршрута, выбранный рабочий центр, верно/неверно, попытки, длительность). GRANT + RLS: сотрудник видит своё, HR/админ — всё.
- XP и уровни: `platform_settings` (правила начисления) + расчёт в `gamification.server.ts`.
- Серверная логика: `simulator.server.ts` (построение маршрута из паспорта, проверка рабочего центра, слои конструкции, подбор дефектов, метрики) и `simulator.functions.ts` (`listProducts`, `startRun`, `submitStep`, `finishRun`, `qualityTask`).
- 3D: пакет `three`, компонент `CableModel3D` рендерится через `React.lazy` внутри `ClientOnly`; геометрия слоёв строится из `cable_constructions` (visual_type, номер слоя).
- Админ-панель: вкладка «Геймификация» переводится на достижения, участки завода и настройки XP; данные тренажёра редактируются в разделе «Производство».
- Цвета только через токены `primary`/`secondary`/`accent`, шрифт Golos Text.

## Ограничение
Тренажёр повышает вовлечённость, но не заменяет аттестацию — тестирование остаётся отдельным модулем и не меняется.
