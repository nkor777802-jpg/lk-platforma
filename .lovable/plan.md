# Подсказка к значку руководителя

## Что делать
Добавить всплывающую подсказку (tooltip) к оранжевому значку руководителя в карточках подразделений, чтобы было понятно его назначение.

- Текст подсказки: «Руководитель подразделения» (если известно ФИО — вторая строка с должностью и ФИО).
- Появляется при наведении мышью и при фокусе с клавиатуры; на сенсорных экранах — по нажатию на значок.
- Подсказка работает во всех местах, где значок используется: обзорная схема, детальная структура ветки, боковая панель подразделения.
- Оформление — стандартный tooltip проекта в фирменных цветах, без изменения самой карточки и логотипа.

## Технически
- Правка только в `src/components/org/HeadBadge` (компонент `HeadBadge` в `src/components/org/OrgPoster.tsx`) — обернуть иконку `UserRoundCog` в `Tooltip`/`TooltipTrigger`/`TooltipContent` из `@/components/ui/tooltip`.
- Иконку сделать доступной для фокуса (`tabIndex=0`, `aria-label`), убрать `aria-hidden`, чтобы подсказка читалась скринридером.
- Проверить, что `TooltipProvider` смонтирован в корне; если нет — добавить локальный провайдер внутри `HeadBadge`.
- Потребители (`OrgPoster.tsx`, `OrgBranch.tsx`, `OrgGraph.tsx`) не меняются.
