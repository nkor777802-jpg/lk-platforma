# ФИО руководителей в схеме оргструктуры

## Что делаем

Во внутренней схеме (страница «Структура предприятия» и вкладка «Схема» в админке) рядом с должностью руководителя показываем его ФИО — там, где оно есть в штатной расстановке.

- Обзорный (постерный) вид: под должностью руководителя — строка с ФИО.
- Детальная структура ветки: то же в карточках узлов.
- Боковая панель подробностей узла: должность + ФИО.
- Подсказка у значка руководителя уже показывает ФИО — приводим формат к единому.

Публичная страница `/structure` остаётся без ФИО: только должности (персональные данные не публикуем).

Если ФИО в ШР не указано — строка просто не выводится, ничего не додумываем.

## Где данных нет (36 из 76 подразделений)

Верхнеуровневые блоки в ШР не имеют собственной руководящей строки — руководитель числится в дочернем отделе. По вашему решению оставляем пусто и передаём вам перечень для ручного заполнения:

Верхний уровень: АДМИНИСТРАТИВНО-УПРАВЛЕНЧЕСКИЙ ПЕРСОНАЛ, Группа планирования и автоматизации, Коммерческая служба, Производственный департамент, Служба безопасности, Служба директора по информационным технологиям, Служба маркетинга, Служба управления персоналом, Финансовая служба.

Второй уровень: Администрация, Группа автоматизации бизнес-процессов, Группа планирования УП, Коммерческая служба (внутр.), ОГТ, Отдел закупок, Отдел защитных конструкций, Отдел информационных технологий, Отдел персонала, Служба директора по качеству, Служба директора по производству, Служба логистики, Техническая служба, Экономический отдел.

Третий-четвёртый уровень: Бюро закупок основного сырья, Бюро закупок ТМЦ и комплектации заказов, Бюро изолированных проводов и кабелей, Бюро кадров, Бюро организации труда и заработной платы, Инженерно-административная группа, Проектный офис, Секретариат дирекции, Секретариат Дирекции, Энерго-механический отдел, Основное производство, Энергетический участок.

Пришлите ФИО по нужным пунктам — добавим их отдельным шагом (правкой данных, без выдумывания).

## Технические детали

- `src/lib/org-tree.ts`: хелпер `headOf(node)` → `{ position, name }` на основе `headPositionOf` и `managerName`.
- `src/components/org/OrgPoster.tsx`, `OrgBranch.tsx`, `OrgGraph.tsx`: вывод ФИО под должностью, только когда `managerName` задан; стиль — мелкий текст токенами (`text-muted-foreground`), перенос слов.
- Публичный источник (`src/lib/public.functions.ts`) уже отдаёт `managerName: null`, поэтому публичная схема автоматически остаётся без ФИО — изменений в серверных функциях не требуется.
