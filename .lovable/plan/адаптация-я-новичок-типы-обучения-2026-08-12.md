# Адаптация «Я Новичок» + типы обучения

Расширяем уже собранную платформу. Новая LMS не создаётся, существующие таблицы, тесты, аналитика, админ-панель и 3D-тренажёр сохраняются.

## 1. Типы обучения (расширение существующего)

- В таблицу назначений добавляется тип программы: первоначальное освоение профессии, повышение разряда, новая профессия, отдельный навык, обязательное обучение.
- Для повышения разряда хранится текущий и целевой разряд, для новой профессии — текущая и целевая профессия, для навыка — привязка к компетенции/рабочему центру/операции.
- Материалы получают область применения: адаптация, профессиональное, обязательное, общее. Один материал доступен нескольким программам.
- Настройки тестов получают классификацию: адаптация, профессиональное, обязательное, аттестация.
- Существующее содержимое помечается как «профессиональное» без потери данных.

## 2. Onboarding — отдельный процесс

Новые сущности только там, где аналога нет:

- Шаблон адаптации и его пункты (тип пункта, относительный срок Day 0/+1/+7/+14/+30/+60/+90/custom, ссылка на материал, видео, тест, ЛНА или контрольную точку).
- Индивидуальная программа сотрудника — снимок шаблона на дату приёма: изменение шаблона не затрагивает уже запущенные программы, даты считаются автоматически от даты приёма.
- Пункты индивидуальной программы со статусом, фактической датой и отметкой наставника.
- Обратная связь сотрудника по контрольным точкам.
- Наставник хранится в профиле сотрудника (ссылка на другого сотрудника), отдельная таблица не заводится.
- Статус адаптации сотрудника: не начата / идёт / завершена.

Разделы контента адаптации (предприятие и история, руководство, структура, фото/видео, экскурсия, первый рабочий день, правила, ЛНА, FAQ, контакты) собираются из уже существующих таблиц контента, материалов, видео, руководства и справочников — дублирующих таблиц не создаём. Профессиональное обучение внутрь адаптации не копируется: показывается только строка прогресса со ссылкой в раздел обучения.

## 3. Личный кабинет

- Новый блок «Что сделать сегодня?» на главной кабинета: единый список задач из адаптации, профессионального обучения, обязательных программ и контрольных мероприятий, отсортированный по сроку, с цветной маркировкой типа.
- Карточки показываются по актуальности: «Я Новичок» (только при активной адаптации), «Моя профессия», «Моё развитие», «Обязательное обучение», «Мои результаты». После завершения адаптации карточка уходит в историю.
- Страница `/onboarding`: шаги по срокам, контрольные точки, наставник и контакты, форма обратной связи, ссылка на профессиональное обучение.
- Профиль расширяется профессиональным паспортом: основная профессия и разряд, дополнительные профессии, активные программы, подтверждённые компетенции, обязательное обучение, результаты тестов, аттестации, история.
- Паспорт компетенций: статусы «Не начато → Изучаю → Выполняю с наставником → Подтверждено». Просмотр материала статус «Подтверждено» не выставляет — его ставит наставник, тест или практическое задание.

## 4. Админ-панель

- Новый раздел «Адаптация» в существующей боковой навигации (доступ admin/hr): новые сотрудники, шаблоны и их пункты, активные программы, материалы адаптации, руководство, завод/экскурсия, ЛНА, наставники, FAQ, контрольные точки, обратная связь, архив. Строится на существующих `EntityManager`/`AdminTable`.
- В разделе «Назначения» — фильтр по типу обучения и выбор типа при создании.
- В форме создания сотрудника — одновременное назначение: шаблон адаптации, первоначальное обучение профессии, обязательные программы, наставник.
- В аналитике — фильтр по типу: адаптация, первоначальное, повышение разряда, новая профессия, навык, обязательное, аттестация.

## 5. Тренажёр и тесты

- Результаты существующего тренажёра связываются с профессией, компетенцией, операцией и рабочим центром; схема допускает будущие сценарии «Найди опасность», «Дефект дня», «До меня → Я → После меня» без переделки.
- Система тестирования используется как есть, добавляется только классификация области.

## 6. Проверка сценариев

Проверим шесть случаев: новый сотрудник (адаптация + первоначальное обучение + обязательные), повышение разряда, новая профессия, отдельный навык, назначенное обязательное обучение, несколько параллельных траекторий у одного сотрудника.

## Технические детали

- Миграции: `ALTER TABLE` для `assignments` (training_type и целевые поля), `materials.material_scope`, `test_settings.test_scope`, `profiles` (mentor_id, hire_date, onboarding_status), `simulator_runs` (связи с компетенцией/рабочим центром); новые таблицы `onboarding_templates`, `onboarding_template_items`, `onboarding_programs`, `onboarding_program_items`, `onboarding_feedback`, `employee_competencies`. Для каждой новой таблицы — GRANT, RLS и политики по существующим функциям `is_admin`/`is_staff`/`manages_user`.
- Серверная логика — новые `src/lib/onboarding.functions.ts` + `onboarding.server.ts` по образцу существующих модулей; агрегатор задач — одна функция, собирающая назначения, пункты адаптации и дедлайны.
- Фронтенд: `src/routes/_authenticated/onboarding.tsx`, блок задач в `dashboard.tsx`, расширение `profile.tsx`, новые разделы `src/routes/_authenticated/admin/onboarding*`.
- Стилистика — только существующие токены брендбука, без новых цветов.
