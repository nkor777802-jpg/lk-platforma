# Выделение отдела безопасности в отдельное подразделение

## Что сейчас
В активной штатной расстановке «Отдел Безопасности» (штат 2) подчинён «Отделу персонала» внутри «Службы управления персоналом».

## Что изменить
Создать самостоятельное подразделение верхнего уровня **«Служба безопасности»**, подчинённое напрямую генеральному директору (root), и перенести в него «Отдел Безопасности».

Итог:
```text
root
├── Служба управления персоналом (штат 13,5 → 11,5)
│   └── Отдел персонала (12 → 10)
└── Служба безопасности (штат 2)
    └── Отдел безопасности (штат 2)
```

## Технические детали
- Добавить строку в `org_snapshot_units` для активной версии: ключ `root/служба безопасности`, parent `root`, level 1, тип «служба».
- Перепривязать «Отдел Безопасности»: новый `external_key` `root/служба безопасности/отдел безопасности`, `parent_key` = `root/служба безопасности`, level 2.
- Обновить `unit_key` у связанных строк в `org_snapshot_positions` и `org_snapshot_assignments` (префикс старого ключа → новый).
- Пересчитать агрегаты `planned_units` / `actual_units` / `vacant_units`: вычесть 2 ед. из «Отдела персонала» и «Службы управления персоналом», проставить их новой службе.
- Подобрать смысловую иконку (щит) для новой службы в логике иконок оргсхемы; код схемы менять не требуется — она строится из данных.
