# Главная страница: оставить только hero-блок

## Что сейчас

Страница `/` дублирует содержимое почти всех разделов меню: «О предприятии»,
«Система обучения», «Структура предприятия» (интерактивная схема),
«Обучение по профессиям», «Преимущества», «Этапы обучения»,
«Частые вопросы», «Контакты». Каждый из этих блоков уже есть как отдельная
страница в шапке — поэтому главная выглядит как «всё меню одним свитком».

## Что сделаем

Оставить на главной только верхний hero-блок:

- заголовок, подзаголовок, две кнопки («Войти в систему обучения»,
  «Возможные профессии для обучения»);
- главная иллюстрация (фото цеха) справа.

Удалить с главной все секции ниже hero. Сами страницы (`/about`, `/structure`,
`/training`, `/training/professions`, `/faq`, `/contacts`) не трогаем —
контент остаётся доступен через меню.

## Техническая часть

- Файл: `src/routes/_public/index.tsx`.
- Убрать все `<Section>`-блоки и связанные импорты (`Section`, `InfoCard`,
  `AnimatedStageList`, `ProfessionGrid`, `OrgStructurePreview`, `Accordion*`,
  контент `about/advantages/faq/platform/stages`), а также loader
  `publicProfessionsQuery` и `useSuspenseQuery`, которые нужны были только
  для удалённых секций.
- `head()` с SEO-мета, canonical и JSON-LD организации сохраняем.
- Hero оставляем в текущем виде, без изменения стилей и логотипа.
