# Документы по ПД: только просмотр + обязательное согласие при первом входе

## Часть 1. Просмотр вместо скачивания

- На публичных страницах «Политика конфиденциальности» и «Согласие на обработку персональных данных» кнопка «Скачать» заменяется на «Открыть документ» — файл открывается во встроенном просмотрщике браузера в новой вкладке, без принудительного сохранения.
- В личном кабинете работника (раздел «Персональные данные: документы») — то же самое: только просмотр, кнопки скачивания и замены нет.
- Скачивание файлов (в т. ч. бланков для физической подписи) остаётся только в админ-панели → «Настройки → Документы по ПД» и только для ролей «Администратор» и «HR». Там же остаётся загрузка новых версий.

## Часть 2. Обязательное согласие при первом входе

- После первого входа сотрудник (любая роль) попадает на экран «Согласие на обработку персональных данных».
- На экране: перечень актуальных документов со ссылками «Открыть», чекбокс «Я ознакомлен(а) и даю согласие на обработку персональных данных» и кнопка «Подтвердить».
- Пока согласие не дано, доступ к личному кабинету и любым внутренним разделам закрыт: пользователя возвращает на экран согласия. Доступен только выход из системы.
- Факт согласия фиксируется в базе: кто, когда и на какую версию документов. Повторно экран не показывается.
- Если админ/HR загрузит новую версию документов, ранее данное согласие остаётся действительным (повторный запрос согласия — отдельная задача, сейчас не делаем).
- В админ-панели в карточке пользователя видно, дано ли согласие и когда.

## Технические детали

1. Миграция: таблица `public.legal_consents` (`user_id`, `document_id`, `document_version` = `uploaded_at` документа, `accepted_at`), уникальность по `(user_id, document_id)`; GRANT для `authenticated` (select/insert) и `service_role`; RLS: пользователь видит и создаёт только свои записи, `admin`/`hr` видят все.
2. `src/lib/legal.functions.ts`: `getMyConsentStatus` (список обязательных документов + признак согласия) и `acceptLegalConsents` (записывает согласие по всем обязательным документам). Обе — с `requireSupabaseAuth`.
3. Новый маршрут `src/routes/_authenticated/consent-required.tsx` c экраном согласия; в `src/routes/_authenticated/route.tsx` в `beforeLoad` — проверка согласия и `redirect` на этот экран (сам экран исключён из проверки).
4. Просмотр: сигнатурные ссылки уже генерируются в `listPublicLegalDocuments`; для просмотра добавляется параметр отображения inline (`download` не передаётся), кнопка меняется на «Открыть» в `LegalDocsDownload.tsx`.
5. `LegalDocsManager.tsx`: у режима `canManage=false` (личный кабинет) кнопка «Скачать» заменяется на «Открыть»; полное скачивание остаётся при `canManage=true` (админ/HR).
6. Стили — существующие токены, без новых цветов.
