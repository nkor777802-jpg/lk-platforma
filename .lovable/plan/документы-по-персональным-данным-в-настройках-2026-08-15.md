# Документы по персональным данным в настройках

## Что появится

В админ-настройках новая вкладка «Документы по ПД» с шестью фиксированными слотами:

Для сайта (публикуются на сайте):

1. Согласие на обработку ПД
2. Согласие на распространение ПД
3. Политика обработки ПД

Для подписи (бланки на печать):
4. Согласие на обработку ПД (бланк)
5. Согласие на распространение ПД (бланк)
6. Политика обработки ПД (бланк)

По каждому слоту: название документа, дата и автор последней загрузки, кнопка «Скачать» и кнопка «Загрузить новую версию» (PDF/DOC/DOCX). Новая загрузка автоматически заменяет текущий документ — на сайте и в кабинете сразу отдаётся свежая версия, старый файл остаётся в истории версий.

Изначально слоты заполняются шестью присланными PDF.

## Где документы видны

- Публичные страницы «Политика конфиденциальности» и «Согласие на обработку ПД» получают блок со ссылками на скачивание актуальных файлов (3 «сайтовых» документа).
- Бланки для подписи доступны для скачивания в админ-панели и в личном кабинете работника (раздел с документами) — по кнопке «Скачать для подписи».

## Права

Загрузка и замена,скачивание  — только роли `admin` и `hr`. Скачивание  бланков для подписи — авторизованным.

## Технически

- Миграция: таблица `public.legal_documents` (slug уникальный, title, kind `site|signature`, storage_path, file_name, mime, size, uploaded_by, updated_at) + `legal_document_versions` для истории. GRANT для `authenticated`/`service_role` (+ `anon` SELECT для kind='site'), RLS: чтение по правилам выше, запись — через `has_role(auth.uid(),'admin'|'hr')`.
- Приватный бакет `legal-docs` (публичные бакеты заблокированы политикой воркспейса), выдача через `signedUrl` из `src/lib/storage.ts`.
- Исходные шесть PDF заливаются в бакет и прописываются в миграции INSERT-строками.
- Серверные функции в `src/lib/legal.functions.ts`: `listLegalDocuments`, `uploadLegalDocument` (проверка роли, запись версии, обновление слота), публичное чтение — в `src/lib/public.functions.ts`.
- UI: новая вкладка в `src/routes/_authenticated/admin/settings.tsx`, компонент `src/components/admin/LegalDocsManager.tsx`; ссылки на страницах `_public/privacy.tsx` и `_public/consent.tsx`.
