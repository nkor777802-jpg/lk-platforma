# Загрузка и отображение фото руководства

## Что делаем

Добавляем в админ-панель раздел «Руководство» с возможностью загружать фотографии руководителей и показывать их в личном кабинете на странице «О компании».

## Почему сейчас не работает

- Таблица `public.management` есть и содержит поле `photo_url`, но она не включена в список `MANAGED_TABLES` в `src/lib/admin.server.ts`, поэтому `EntityManager` не может ею управлять.
- `EntityManager` поддерживает только текстовые поля; загрузку файлов не умеет.
- На странице `src/routes/_authenticated/company.tsx` фото руководителя не выводится.

## План работ

### 1. Хранилище для фото

- Создать бакет `management` (или использовать существующий `materials`, если проще) через инструмент управления хранилищем.
- Добавить RLS-политики на `storage.objects`: администратор/HR могут загружать и удалять; все аутентифицированные пользователи могут получать подписанные ссылки для чтения.
- Публичные бакеты заблокированы политикой воркспейса, поэтому для отображения использовать подписанные ссылки (`createSignedUrl`), как уже сделано для материалов.

### 2. Серверная часть

- Добавить `management` в `MANAGED_TABLES` (`src/lib/admin.server.ts`) с мягким удалением по `is_active`.
- Добавить серверную функцию загрузки фото руководителя:
  - принимает `File` и `management_id`;
  - загружает в бакет `management/management_id/<timestamp>-<filename>`;
  - возвращает путь;
  - обновляет `photo_url` в таблице `management`.
- Добавить серверную функцию удаления фото (очистка `photo_url` и удаление объекта из бакета).

### 3. Админ-панель

- На странице `src/routes/_authenticated/admin/org.tsx` добавить вкладку «Руководство».
- Реализовать для неё отдельный редактор (не универсальный `EntityManager`), потому что нужна загрузка файла:
  - поля: ФИО, должность, биография, фото (drag-and-drop или input type="file"), порядок, активность;
  - превью загруженного фото;
  - кнопка «Удалить фото».
- Доступ только для ролей `admin` и `hr`.

### 4. Личный кабинет

- В `src/routes/_authenticated/company.tsx` в разделе «Руководство» выводить фото каждого руководителя.
- Использовать `signedUrl()` из `src/lib/storage.ts` (или аналог) для получения подписанной ссылки по `photo_url`.
- Предусмотреть запасной вариант (инициалы/заглушка), если фото отсутствует.

### 5. Проверка

- Собрать проект (`bun run build`).
- Войти как администратор, открыть `/admin/org` → «Руководство», добавить руководителя с фото.
- Открыть `/company` → «Руководство» и убедиться, что фото отображается.

## Что остаётся без изменений

- Существующие таблицы `departments`, `positions`, `groups` и их редакторы.
- Публичная часть сайта и брендинг.
- Логика тестирования, геймификации и аналитики.
