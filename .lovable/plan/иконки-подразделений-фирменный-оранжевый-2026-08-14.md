# Иконки подразделений — фирменный оранжевый

Сейчас кружки с иконками окрашены в синий/нейтральные оттенки (`KIND_CLASS` в `src/components/org/OrgPoster.tsx`). Нужно, чтобы сама иконка везде была фирменного оранжевого цвета бренда.

## Что делаем

- В `OrgPoster.tsx` меняем классы кружка иконки: фон — мягкий оранжевый (`bg-primary/10`), рамка — `border-primary/30`, сама иконка — `text-primary` (оранжевый #E3661D через токен).
- Для тёмных карточек (root — сплошной оранжевый фон, shop — синий фон) иконка остаётся контрастной (`text-primary-foreground` / `text-secondary-foreground`), чтобы не сливалась.
- Те же классы автоматически применяются в детальной структуре департамента (`OrgBranch.tsx`), так как она использует общий `KIND_CLASS`.
- Названия подразделений, кнопки и остальная типографика не меняются.

## Технически

Правится только карта `KIND_CLASS` (и при необходимости `KIND_META`) в `src/components/org/OrgPoster.tsx`. Используются существующие семантические токены из `src/styles.css`, без хардкода цветов.
