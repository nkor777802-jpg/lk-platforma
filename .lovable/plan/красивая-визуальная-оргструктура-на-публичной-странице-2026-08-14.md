# Красивая визуальная оргструктура на публичной странице

Сейчас публичная страница `/structure` показывает не схему, а вложенный список с переключателем режимов («Оргструктура / Подразделения / Должности / Штат / Производство») — семь вариантов вместо одной наглядной картинки. Данные при этом уже загружены из штатной расстановки (74 подразделения, 187 должностей).

## Что будет сделано

1. **Одна схема вместо режимов.** С публичной страницы убираются переключатель режимов и лишние панели. Остаётся единая схема предприятия.
2. **Настоящий граф сверху вниз.** Корень «АО «Людиновокабель»» — крупная карточка по центру, ниже уровни подразделений, соединённые линиями-связями (как в классической оргсхеме), а не отступами списка. Глубокие уровни раскрываются по клику на карточке.
3. **Фирменное оформление.** Уровни различаются цветом по брендбуку: верхний уровень — оранжевый, дирекции/подразделения — синий, участки и службы — бирюзовый. Мягкие тени, скруглённые карточки, плавные линии связей, аккуратная анимация раскрытия ветки.
4. **Содержимое карточки.** Название подразделения, тип, руководитель подразделения (без ФИО рядовых работников), штатная численность и число вложенных подразделений/должностей. Клик по карточке открывает боковую панель с подробностями: перечень должностей и численность.
5. **Управление схемой.** Поиск по подразделениям и должностям с подсветкой и авто-раскрытием ветки; зум колесом/кнопками и перетаскивание полотна мышью; «Развернуть всё / Свернуть всё»; полноэкранный режим.
6. **Телефон.** Тот же визуальный стиль, но пошаговая навигация: карточка текущего подразделения, «хлебные крошки» и список дочерних — без горизонтальной прокрутки.
7. **Главная страница.** Блок структуры приводится к тому же виду: цифры + верхний уровень карточками в фирменных цветах и кнопка «Смотреть полную схему».

Внутренний раздел для сотрудников (`/org-structure`) и админ-панель с импортом ШР и версиями остаются как есть — там расширенные режимы и экспорт нужны для работы.

## Технические детали

- Новый компонент `src/components/org/OrgGraph.tsx`: рекурсивная раскладка «сверху вниз» на flex-колонках с CSS-псевдоэлементами для соединительных линий; зум/пан через обёртку с `transform: scale/translate` и обработчиками указателя; без внешних библиотек графов.
- Цвет уровня берётся из токенов `src/styles.css` (`--primary` / `--secondary` / `--accent`), хардкод hex не используется.
- Панель деталей — `Sheet` из shadcn; поиск переиспользует `keysMatching`/`ancestorsOf` из `src/lib/org-tree.ts`.
- `src/routes/_public/structure.tsx` рендерит `OrgGraph` вместо `OrgChart` (`variant="public"`); `OrgChart` остаётся для `/org-structure` и админки без изменений.
- `src/components/public/OrgStructurePreview.tsx` — обновление стилей карточек верхнего уровня под ту же палитру.
- Данные и серверные функции не меняются: используется существующий `publicOrgStructureQuery`.
