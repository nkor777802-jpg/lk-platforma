# Модуль аналитики (07_Analytics)

Ниже — разрешение спорных пунктов спецификации в пользу минимальных изменений существующей архитектуры, плюс состав работ.

## Решения по конфликтам

1. **Доступ сотрудника к аналитике** — отдельный админ-раздел не трогаем. Личная аналитика остаётся в личном кабинете: на странице «Развитие» добавляется блок «Моя статистика» (свои попытки, средний балл, динамика, прогресс по назначениям). Права к админ-функциям не расширяем.
2. **Руководитель (manager)** — видит аналитику только по своим подчинённым. Используем существующую функцию `manages_user`, фильтрация на сервере, а не в UI.
3. **Экспорт отчётов** — переиспользуем существующий CSV-экспорт. PDF/XLSX не добавляем; печать в PDF — через браузер из готового HTML-протокола.
4. **Метрики, которых нет в схеме** (время в системе, количество входов) — исключаем из первой версии, ничего не выдумываем. Вместо них — активность по фактическим событиям: попытки тестов, прогресс обучения, тренажёры.
5. **Обновление данных** — без realtime-подписок: инвалидация TanStack Query по событиям (завершение теста, проверка ответа, изменение назначения) плюс ручное обновление — как в остальных модулях.
6. **Нумерация документа** — считаем опечаткой (06 занят геймификацией), файл трактуем как 07.

## Что будет сделано

**Серверная логика** — новые `src/lib/analytics.server.ts` и `src/lib/analytics.functions.ts` (существующий `admin.functions.ts` не меняем):
- сводные KPI: обученные, средний балл, доля сдач, просроченные назначения, активные пользователи;
- срезы: по сотрудникам, подразделениям, профессиям, курсам, тестам (сложность вопросов, доля ошибок);
- динамика по периодам (месяц/квартал/год);
- фильтры: период, подразделение, профессия, курс, роль.

**Права:** admin/hr — всё; teacher — обучение и тесты; manager — только подчинённые; employee — только свои данные через отдельную личную функцию.

**Интерфейс:**
- `/admin/analytics` — дашборд: KPI-карточки, графики recharts (динамика, распределение баллов, топ проблемных тем), таблицы срезов на существующем `AdminTable`, панель фильтров, экспорт CSV.
- Блок «Моя статистика» на странице сотрудника (без нового маршрута).
- Пункт «Аналитика» в сайдбаре админки.

**Дизайн:** только существующие токены бренда и компоненты, новой стилистики не вводим.

## Технические детали

- Новые файлы: `src/lib/analytics.server.ts`, `src/lib/analytics.functions.ts`, `src/lib/analytics-queries.ts`, `src/routes/_authenticated/admin/analytics.tsx`; правки — пункт меню в `admin/route.tsx` и блок статистики на странице развития.
- Все функции — `createServerFn` с `requireSupabaseAuth`; агрегация на сервере, не в браузере.
- Изменения схемы БД не требуются.
