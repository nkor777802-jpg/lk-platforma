# Модуль геймификации (06_Gamification)

Достраиваем модуль поверх существующей архитектуры. Testing System, Personal Account и Professional Development не переписываем — только используем их данные.

## Что уже есть и переиспользуется
- Таблицы `practical_tasks`, `practical_task_items`, `practical_results` (типы `sequence`, `match` уже проверяются на сервере).
- Таблицы `achievements`, `employee_achievements` с полями `condition_type` / `condition_value`.
- Роли, RLS, аудит, админ-панель на `EntityManager`, дизайн-токены бренда.

## Что добавляем

### 1. База данных (только новое)
- Новые типы производственных тренажёров для `practical_tasks`: сборка конструкции кабеля, маршрут изготовления, выбор рабочего центра, поиск технологической ошибки, контроль качества по фото, комплексная производственная смена.
- Таблицы `factory_zones` (участки виртуального завода: волочение, скрутка, изоляция, бронирование, оболочка, лаборатория, склад) и `employee_factory_zones` (открытые участки).
- Таблица `profession_collection` — открытые карточки освоенных профессий.
- Ключи в `platform_settings`: включение/отключение рейтингов и модуля геймификации.
- Наполнение справочника достижений восемью позициями из спецификации.

### 2. Серверная логика (новые файлы)
- `gamification.server.ts`: пересчёт достижений, открытие участков завода и карточек профессий по факту обучения/тестов; расчёт рейтингов по подразделениям, профессиям и активности.
- `gamification.functions.ts`: `myGamification`, `listLeaderboards`, `listTrainers`, `submitTrainer` (проверка ответа строго на сервере).
- Точка интеграции: после завершения попытки теста добавляется один вызов пересчёта достижений в существующий `finishAttempt`; его логика не меняется.

### 3. Интерфейс сотрудника
- Новый раздел «Развитие навыков» (`/gamification`) с вкладками: Тренажёры, Квесты, Достижения, Виртуальный завод, Коллекция профессий, Рейтинг.
- Тренажёры: выбор и перестановка элементов (сборка кабеля, порядок операций, сопоставление оборудования, поиск ошибки, дефекты по фото); результат сохраняется в `practical_results`.
- Достижения: карточки полученных и закрытых наград с прогрессом.
- Рейтинг: три вкладки, полностью скрывается при отключении в настройках.
- Карьерный прогресс — ссылкой на существующий раздел «Развитие», без дублирования логики.

### 4. Админ-панель
- Раздел `/admin/gamification`: управление тренажёрами и их элементами, достижениями, участками завода, переключатели рейтингов и модуля.

## Технические детали
- Проверка ответов тренажёров только в server functions; клиенту не отдаются признаки правильности до отправки.
- Все новые таблицы: GRANT + RLS (сотрудник видит своё, HR/админ — всё, справочники читают авторизованные).
- Стили только через токены `primary`/`secondary`/`accent`, шрифт Golos Text, без хардкода цветов.

## Возможные противоречия
Явных конфликтов не обнаружено: практические задания и достижения уже заложены в схему и расширяются, а не переделываются. Если расхождение всплывёт при реализации, работа останавливается и пункты выносятся на согласование.
