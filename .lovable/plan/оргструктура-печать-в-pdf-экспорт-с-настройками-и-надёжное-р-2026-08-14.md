# Оргструктура: печать в PDF, экспорт с настройками и надёжное раскрытие

## Что получит пользователь

- Кнопка «Экспорт» на схеме открывает окно с выбором формата (**PDF**, PNG, SVG), масштаба (1x / 2x / 3x) и фона (белый, светло-серый, прозрачный).
- PDF формируется из **текущего вида**: выбранная ветка (подразделение) и текущее состояние раскрытых узлов сохраняются один в один. Дополнительно можно выбрать «Раскрыть всю ветку перед экспортом».
- Автоподбор ориентации A4/A3 (альбомная для широких схем) и вписывание схемы в лист без обрезки; в подвале — название подразделения, версия ШР и дата.
- Экспорт и печать доступны только ролям **admin** и **hr**; для остальных кнопки скрыты, а страница `/org/print` показывает сообщение об отсутствии прав.
- Раскрытие веток запоминается отдельно для каждого подразделения; после очистки поиска дерево возвращается в состояние до поиска, а не сбрасывается.

## Как это будет сделано

**PDF-экспорт (клиентский, без сервера)**
- В `src/components/org/OrgGraph.tsx` рендерим текущий контейнер схемы через `html-to-image` (`toPng` с выбранным `pixelRatio` и `backgroundColor`), затем вкладываем картинку в PDF через `jspdf` (новая зависимость).
- Ориентация и формат листа выбираются по соотношению сторон снимка; изображение масштабируется по меньшему из коэффициентов ширины/высоты с полями 8 мм.
- Имя файла: `Оргструктура_<Подразделение>_<дата>.pdf`.
- Альтернативный маршрут печати `/org/print` остаётся для табличного PDF и уже принимает `focus`; добавим передачу параметра `open` (список раскрытых ключей), чтобы печать совпадала с экраном.

**Диалог экспорта**
- Заменяем текущие кнопки PNG/SVG на одну кнопку «Экспорт» + `Dialog` с радиогруппами: формат, масштаб, фон, охват («текущий вид» / «вся ветка»).
- Для охвата «вся ветка» перед снимком временно раскрываем все узлы ветки, ждём кадр отрисовки, снимаем, восстанавливаем прежнее состояние.

**Права**
- В `OrgGraph.tsx`, `OrgStructureViewer.tsx` — гейт по `useAuth().isStaff` (admin/hr) для кнопок экспорта, Excel и печати.
- В `src/routes/org.print.tsx` — проверка роли через новую серверную функцию `canPrintOrgStructure` (уже добавлена в `src/lib/org.functions.ts`), при отказе показываем «Недостаточно прав».

**Состояние раскрытия**
- `expandedByBranch: Record<branchKey, string[]>` вместо одного `Set`; ключ — выбранная ветка или `__all`.
- Снимок состояния перед поиском и восстановление при очистке поиска.
- Синхронизация `focus` и `open` с URL, чтобы ссылка и печать воспроизводили вид.

## Технические детали

- Новая зависимость: `jspdf` (работает в браузере, серверный рантайм не затрагивается).
- Файлы: `src/components/org/OrgGraph.tsx` (основные изменения), `src/components/org/OrgStructureViewer.tsx`, `src/routes/org.print.tsx`, `src/lib/org.functions.ts`.
- Текущая правка `OrgGraph.tsx` не завершена (есть ошибки компиляции по старым кнопкам PNG/SVG и `setExpanded`) — они устраняются в рамках этого же плана.
