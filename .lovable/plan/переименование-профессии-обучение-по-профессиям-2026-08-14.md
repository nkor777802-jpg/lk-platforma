# Переименование «Профессии» → «Обучение по профессиям»

## Что меняется
Во всех местах, которые видит пользователь, пункт и заголовок «Профессии» получают название «Обучение по профессиям»:

- Меню публичного сайта (шапка) — пункт навигации.
- Меню личного кабинета — пункт навигации.
- Публичная страница профессий — заголовок H1, title, описание и хлебные крошки.
- Страница профессий в кабинете — H1, title/og-заголовки, пустое состояние.
- Ссылка «Профессии и программы» на странице обучения → «Обучение по профессиям».

Не меняются: административные справочники, вкладки аналитики, шаблоны импорта/экспорта — там «Профессии» остаётся как название справочника/сущности. Адреса страниц (/training/professions, /professions) не меняются.
