# План: раздел «Заявки на обучение / Обращения» в админ-панели

## Текущее состояние
- Форма обращения на сайте (`/contacts` и в публичных разделах) отправляет данные в таблицу `public.contact_requests` через серверную функцию `submitContactRequest`.
- В админ-панели сейчас нет раздела для просмотра этих заявок — они сохраняются в базе, но не видны через интерфейс.
- Таблица `contact_requests` содержит поля: `id`, `full_name`, `unit`, `email`, `phone`, `message`, `consent`, `status`, `created_at`, `updated_at`.

## Что нужно сделать
1. **Добавить раздел в админ-панель**
   - Новый пункт меню «Заявки» (или «Обращения») в `/admin/route.tsx`.
   - Маршрут `/admin/requests`.
   - Доступ: `admin`, `hr`.

2. **Серверные функции**
   - `listContactRequests` — получение списка с фильтрами по статусу и поиском по ФИО/email/телефону.
   - `updateContactRequestStatus` — смена статуса (`new`, `in_progress`, `done`, `archived`) и добавление комментария.
   - Проверка ролей через `requireSupabaseAuth`.

3. **Интерфейс просмотра заявок**
   - Таблица с колонками: дата, ФИО, подразделение, контакты, статус, действия.
   - Фильтры по статусу.
   - Карточный вид для мобильных устройств.
   - Детальный просмотр заявки в Drawer/Dialog с полным текстом сообщения.

4. **Уведомления**
   - Опционально: badge в меню админ-панели с количеством новых заявок.

## Критерии приёмки
- Администратор/HR может открыть `/admin/requests` и увидеть все заявки.
- Можно изменить статус заявки.
- Мобильная версия корректно отображает список.
- Данные читаются только авторизованными пользователями с ролями `admin`/`hr`.
