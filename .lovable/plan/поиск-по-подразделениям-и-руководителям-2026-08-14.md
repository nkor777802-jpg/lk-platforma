# Поиск по подразделениям и руководителям

Сейчас в схеме есть поле поиска, но оно только подсвечивает найденные карточки и раскрывает ветки — списка результатов на десктопе нет, а перейти к нужной карточке одним кликом нельзя. На мобильном список есть, но он показывает только название подразделения без пояснения, почему строка попала в выдачу.

## Что будет сделано

1. **Расширить условие совпадения**
   Поиск будет учитывать: название подразделения, тип подразделения, должность руководителя, любые должности штатного расписания и (во внутреннем режиме) ФИО руководителя. Регистр и лишние пробелы игнорируются.

2. **Выпадающий список результатов на десктопе**
   Под полем поиска появится панель с найденными подразделениями (до 20 шт.):
   - название подразделения,
   - путь в структуре (например «АО «Людиновокабель» › Коммерческая служба»),
   - причина совпадения — должность или ФИО, по которым нашлось, подсвеченная фрагментом запроса,
   - счётчик «Найдено: N» и состояние «Ничего не найдено».

3. **Переход к карточке по клику**
   Клик по результату раскрывает всех предков узла, прокручивает схему к карточке и подсвечивает её на пару секунд. Если узел лежит вне текущей ветки фокуса — фокус сбрасывается на общий обзор, затем происходит переход.

4. **Мобильный режим**
   В существующий список результатов добавляются путь и причина совпадения; клик по-прежнему открывает подразделение.

5. **Мелочи UX**
   Крестик для очистки запроса в поле, `Esc` закрывает выдачу, `Enter` переходит к первому результату.

- `src/components/org/OrgGraph.tsx`: локальное состояние `resultsOpen`, панель результатов под инпутом, обработчик `goToNode(key)` (раскрытие предков через `ancestorsOf`, `scrollIntoView` по `data-node-key`, временная подсветка), обновление мобильного списка.
