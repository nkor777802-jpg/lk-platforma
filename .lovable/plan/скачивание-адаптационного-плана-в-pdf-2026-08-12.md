# Скачивание адаптационного плана в PDF

Добавляем возможность выгрузить программу «Я Новичок» в PDF: список мероприятий с днями (День 0 / +N), плановыми датами и статусами.

## Где появится кнопка

- Личный кабинет, страница «Я Новичок» — кнопка «Скачать план (PDF)» рядом с заголовком (сотрудник скачивает свой план).
- Админ-панель, «Адаптация» → «Программы новичков» — кнопка выгрузки у каждой программы (HR/админ скачивает план любого сотрудника).

## Что будет в документе

- Шапка: логотип и наименование АО «Людиновокабель», заголовок «Программа адаптации», ФИО сотрудника, должность/профессия, наставник, дата приёма, название шаблона, статус программы, процент выполнения.
- Таблица мероприятий, сгруппированная по разделам, с колонками: № , Мероприятие, Тип, День (День 0 / День +N), Плановая дата (hire_date + offset), Обязательность, Статус (К выполнению / Ждёт наставника / Выполнено / Подтверждено), Дата выполнения.
- Подвал: дата формирования документа и место для подписей сотрудника и наставника.

## Как это работает

Отдельная страница-«печатная форма» `/onboarding/print` (и `?programId=` для HR), оформленная под А4 в фирменных токенах, открывается в новой вкладке и сразу вызывает системный диалог печати — пользователь сохраняет в PDF. Это даёт корректную кириллицу, фирменные шрифты и не требует новых зависимостей.

## Технические детали

- Новый серверный метод `onboardingPlanForPrint` в `src/lib/onboarding.functions.ts`: без аргумента возвращает свою программу, с `programId` — любую (доступ только admin/hr/наставник), реализация в `src/lib/onboarding.server.ts` поверх существующих выборок `onboarding_programs` / `onboarding_program_items`.
- Новый роут `src/routes/_authenticated/onboarding.print.tsx` вне AppShell-хрома: рендерит документ, печатные стили (`@media print`, `@page { size: A4; margin: 12mm }`) добавляются локально в этом роуте.
- Даты считаются как `hire_date + offset_days` (уже есть `dueFromOffset` в `src/lib/training-types.ts`), подписи статусов берутся из существующих словарей.
- В `src/routes/_authenticated/onboarding.tsx` и `src/routes/_authenticated/admin/onboarding.tsx` добавляются только кнопки-ссылки; существующая логика не меняется.
