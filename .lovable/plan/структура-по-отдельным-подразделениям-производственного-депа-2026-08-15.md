# Структура по отдельным подразделениям производственного департамента

Сейчас подробную схему можно открыть только для подразделения верхнего уровня (например, всего Производственного департамента). Внутренние службы (Служба директора по производству, ОТТ, Техническая служба, Отдел закупок, Служба логистики, Цех № 1 и т. д.) видны только как ветки внутри общей большой схемы — отдельную схему по ним построить нельзя.

## Что добавим

1. **Панель выбора подразделения внутри ветки.** При открытой ветке (например, «Производственный департамент») над схемой появляется строка чипов с её дочерними подразделениями. Клик по чипу переключает схему на это подразделение — оно становится корнем схемы.
2. **Быстрый переход с любой карточки.** В карточке подразделения (и в боковой панели деталей) появляется действие «Показать структуру подразделения» — открывает схему именно этого узла на любом уровне вложенности.
3. **Хлебные крошки.** Путь «Вся структура → Производственный департамент → Служба директора по производству» с кликом на любой уровень для возврата.
4. **Раздельная память состояния.** Раскрытые узлы, режим просмотра («Дерево» / «Один лист») и масштаб сохраняются отдельно для каждого выбранного подразделения; выбор отражается в адресной строке, ссылкой можно поделиться.
5. **Экспорт по подразделению.** Экспорт PNG/SVG/PDF и печать работают для текущего выбранного подразделения (имя файла — по названию подразделения). Доступ к экспорту остаётся только у ролей «админ» и «HR».

Данные не меняются: подразделения, названия и должности берутся только из импортированной штатной расстановки.

## Технические детали

- `src/components/org/OrgGraph.tsx`: `focusKey` перестаёт быть привязанным к верхнему уровню — фокусироваться можно на любом узле через `findNode(allRoots, key)`; хлебные крошки строятся из `pathTo`. Добавляется панель чипов дочерних узлов текущего фокуса и обработчик `focusChild`. Ключ ветки `branchId` уже используется для `expandedByBranch` — состояние вида (`view`) также переводится в словарь по ветке. URL-синхронизация `?focus=&view=&open=` остаётся, добавляется корректный сброс при смене фокуса.
- `src/components/org/OrgBranch.tsx`: в карточке узла с детьми — кнопка «Открыть как схему», вызывающая новый проп `onFocus(node)`.
- `src/components/org/OrgPoster.tsx`: без изменений логики, только проброс существующего `onOpenBranch`.
- Экспорт (`runExport`) и режим печати `src/routes/org.print.tsx` используют текущий `focusKey`, поэтому меняются минимально — только подпись и имя файла.
