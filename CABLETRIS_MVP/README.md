# CABLETRIS_MVP

Готовый стартовый пакет для Cursor для первой версии игры «КабельТрис».

## Что внутри

- `CURSOR_PROMPT.md` — техническое задание для Cursor.
- `data_products.json` — три продукта первого уровня с ID из мастер-каталога.
- `game_config.json` — параметры поля, скорости, очков и первого заказа.
- `assets/products/` — три изображения продукции для MVP.

## Продукты MVP

1. `01-008` — АВБШвнг(А) — Силовые кабели.
2. `02-014` — КВВГ — Контрольные кабели.
3. `03-005` — СИП-3 — Провода СИП.

## Почему именно три разных семейства

Первый прототип должен проверить механику падения, управления, визуальную читаемость карточек и merge. Поэтому продукты намеренно визуально различимы. После стабилизации игрового ядра список заменяется/расширяется через data adapter без изменения механики.

## Как передать Cursor

1. Распаковать папку `CABLETRIS_MVP` в корень существующего репозитория обучающей платформы.
2. Открыть весь репозиторий в Cursor, а не только эту папку.
3. Открыть Agent/Chat в Cursor.
4. Передать содержимое `CABLETRIS_MVP/CURSOR_PROMPT.md` либо написать: `Выполни задачу из CABLETRIS_MVP/CURSOR_PROMPT.md. Сначала изучи проект и дай краткий план, затем реализуй.`
5. После реализации проверить игру на ПК и в мобильном режиме DevTools.

## Важно

Не переносить эти JSON как финальную базу платформы. Это data layer для MVP. Cursor обязан оставить адаптер, чтобы позже подключить существующую базу продукции/админ-панель.
