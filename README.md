# Платформа обучения и аттестации — АО «Людиновокабель»

Корпоративная веб-платформа кабельного завода: обучение персонала, тестирование
и аттестация, сертификаты, онбординг, развитие компетенций и интерактивная
организационная структура предприятия.

## Возможности

**Публичный сайт**
- Сгруппированная навигация: меню «АО «Людиновокабель»» (О предприятии,
  Структура, Руководство) и «Структура обучения» (Структура обучения,
  Возможные профессии для обучения)
- Кнопка «Моё обучение» в шапке: для авторизованных ведёт в личный кабинет,
  для гостей — на страницу входа; рядом кнопка выхода из системы
- Главная страница — только hero-блок, остальные разделы доступны через меню
- О предприятии, руководство, контакты, частые вопросы, политики и согласия
- Организационная структура: интерактивная схема с поиском и детализацией по департаментам

**Личный кабинет работника**
- Курсы, уроки и учебные материалы, видеотека, библиотека
- Тестирование и аттестация, результаты попыток, сертификаты
- Онбординг, индивидуальные планы развития, компетенции
- Геймификация (достижения), 3D-тренажёр производственных процессов

**Админ-панель**
- Пользователи и роли, назначения обучения, заявки и проверки
- Тесты, курсы, материалы, справочники, продукция и производство
- Импорт штатной расстановки и версии оргструктуры
- Настройки → «Документы по ПД»: загрузка и скачивание документов по обработке
  персональных данных
- Аналитика, аудит действий, экспорт данных, настройки платформы

## Документы по персональным данным

- Три документа для сайта и три бланка для физической подписи хранятся в
  приватном хранилище; каждая загрузка сохраняется в истории версий
- Публично и в личном кабинете документ можно только **открыть** для просмотра
- **Скачивание** и загрузка новых версий доступны только ролям `admin` и `hr`
  в админ-панели (Настройки → «Документы по ПД»); загруженный файл
  автоматически становится актуальным, предыдущий уходит в историю
- При первом входе работник обязан подтвердить согласие галочкой: без этого
  доступ в личный кабинет заблокирован экраном согласия (`/legal-consent`)

## Роли и доступ

Роли: `employee`, `manager`, `hr`, `admin`, `teacher`. Хранятся в отдельной
таблице `user_roles`, проверяются через функцию `has_role` и политики RLS.
Экспорт и печать оргструктуры доступны только `admin` и `hr`.

## Стек

- TanStack Start (файловый роутинг) + React 19 + TypeScript
- Vite 7, Tailwind CSS v4, shadcn/ui, TanStack Query
- Lovable Cloud: база данных, аутентификация, storage
- Серверные функции (`createServerFn`) вместо отдельного бэкенда

## Модуль «Организационная структура»

- Версии структуры: действующая (Active) и черновики (Draft) с историей изменений
- Версионный импорт штатной расстановки (Excel) с маппингом колонок:
  черновик → сравнение с действующей версией → публикация → откат
- Режимы просмотра: вся структура, «одним листом», отдельная ветка департамента
- Отдельная схема по любому подразделению (в том числе внутри производственного
  департамента) с хлебными крошками и чипами дочерних подразделений
- Режим просмотра и состояние раскрытых узлов запоминаются для каждой ветки отдельно
- Должности и ФИО руководителей на карточках, значок руководителя со всплывающей подсказкой
- Показатель штатной численности с выделением основных производственных рабочих
  и указанием текущего года
- Поиск по подразделениям, должностям и руководителям
- Экспорт схемы в PNG, SVG и PDF с выбором масштаба и фона (admin, HR)

Персональные данные: публично отображаются ФИО только топ-руководства
(генеральный директор и руководители верхнего уровня) — фильтрация выполняется
на сервере. ФИО руководителей вложенных отделов видны после входа в систему,
ФИО рядовых работников на схемах не публикуются.

Единственный источник истины по подразделениям — импортированная штатная
расстановка. Подразделения и названия не придумываются вручную.

## Дизайн-система

Фирменные цвета «Людиновокабель»: оранжевый `#E3661D` (основной),
синий `#112866` (дополнительный), бирюзовый `#399EAD` (акцент).
Шрифт — Golos Text. Все цвета подключены как семантические токены в
`src/styles.css`; хардкод hex-значений и утилит вроде `text-white` в
компонентах запрещён. Логотип используется без изменений.

## Локальный запуск

Нужны Node.js и npm ([установка через nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

Переменные окружения для подключения к бэкенду (Lovable Cloud) создаются
автоматически в `.env` — редактировать их вручную не нужно.

## Разработка в Lovable

Проект создан и развивается в [Lovable](https://lovable.dev): изменения из
редактора коммитятся в репозиторий, а пуш в подключённую ветку синхронизируется
обратно в редактор.
